# rs1ngh13.github.io

Personal site for Rajdeep Singh, served by GitHub Pages at https://rs1ngh13.github.io/.

Plain static HTML, no build step (`.nojekyll`). Edit `index.html` for content, `assets/css/site.css` for styling, and replace `assets/resume.pdf` to update the downloadable resume. Preview locally with `python3 -m http.server`.
